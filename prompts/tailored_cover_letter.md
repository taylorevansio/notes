# 1 - Points
## 1.1 - Rough Draft
```
Go through our entire conversation, my resume, and the target job description and provide a reason I would be a good fit for the job. Provide a point that appeals to logic, a point that shows my emotional commitment, and a point that shows moral/ethical alignment between myself and the employer (or the job function).
```

## 1.2 - Shorten Points
```
Describe each point in one concise sentence, less than 8 words, following the format: I VERB BRIEF_AND_SHORT_VALUE_KEYWORD_OR_PHRASE
```

## 1.3 - Find Supporting Examples
```
Here are the final points:
- LOGOS_POINT
- PATHOS_POINT
- ETHOS_POINT

For each sentence, which will operate as headings, find me three supporting examples from my resume. Think through why each example supports its respective heading, then construct the example as a bullet. 

Only use examples that show me going above and beyond the bare minimum, basic decency, basic ethics, and professional expectations. For example, protecting private data is not an example of integrity. It's the bare minimum.
```
